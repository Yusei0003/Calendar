# KESEN LARUS スタッフカレンダー

KESEN LARUS のスタッフで予定を共有するためのカレンダーです。
スタッフ個人の予定と、店舗全体のイベント・営業スケジュールを1つの画面で扱えます。

- **仕様**: [docs/spec.md](docs/spec.md)
- **公開までの手順**: [docs/setup.md](docs/setup.md)

## できること

- 月 / 週 / 日 / リストの4つの表示。スマホはリスト、PCは月から始まります
- 日表示はスタッフごとに列が分かれ、誰が何をしているか一目で分かります
- 予定をドラッグして日時を変更、上下の端を引っ張って時間を伸縮
- 変更・削除はすべて「元に戻す」で取り消せます（Ctrl+Z / Cmd+Z も可）
- スタッフ・分類での絞り込み
- 端末の設定に合わせたライト／ダーク表示（手動切替も可）
- スタッフと分類は設定画面からいつでも追加・変更できます
- 各自の Google カレンダーの予定を読み取り専用で取り込んで表示（任意・本人設定）

## 使い方

1. 配られたURLを開く
2. スタッフ共通の**合言葉**を入力する
3. **自分の名前を選ぶ**（この端末に記憶され、予定の登録者として記録されます）

名前を選び直すときは、右上の自分の名前を押します。

## 技術構成

| 領域 | 採用 |
|------|------|
| フレームワーク | Next.js (App Router) + TypeScript |
| データベース | Supabase (PostgreSQL) |
| スタイル | Tailwind CSS |
| 公開先 | Vercel |

データベースへのアクセスはすべてサーバー側を経由し、ブラウザに接続キーを渡しません。
詳しくは [docs/spec.md](docs/spec.md) の1章を参照してください。

## 開発

```bash
npm install
cp .env.example .env.local   # APP_PASSCODE と SESSION_SECRET を記入
npm run dev                  # http://localhost:3000
```

Supabase の環境変数が未設定のときは、データを `.data/db.json` に保存して動きます
（手元で試すためのもので、本番では使われません）。

```bash
npm test            # 日時計算・重なり配置・ドラッグ計算のテスト
npm run build       # 本番と同じ形に組み立てる
npm run passcode -- <合言葉>   # 合言葉のハッシュを作る
```
